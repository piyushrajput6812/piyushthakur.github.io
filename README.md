# Piyush Thakur — Personal Portfolio

A custom responsive portfolio website designed for GitHub Pages.

## Files
- `index.html` — main website
- `style.css` — complete visual design and responsive CSS
- `script.js` — navigation, reveal animations and dynamic year
- `CNAME` — custom domain configuration

## Publish on GitHub Pages
1. Create a GitHub repository, preferably `YOUR-GITHUB-USERNAME.github.io`.
2. Upload `index.html`, `style.css`, `script.js`, `CNAME`, and the `assets` folder.
3. Go to Settings → Pages.
4. Select the publishing source (usually `Deploy from a branch`, branch `main`, folder `/root`).
5. Save.
6. Configure your custom domain in Settings → Pages.

## Important
Replace `assets/Piyush_Thakur_CV.pdf` with your actual CV PDF. You can also replace the social URLs in `index.html` with your exact profiles.
